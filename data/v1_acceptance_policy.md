# v1 样本验收记录

用户授权：继续推进，并由 Codex 验收样本质量。验收负责人为 Codex；不把未发生的人工审核写成已完成，也不要求用户代为逐条审核。

此次输入是本项目原创的受控句式数据。125 个中英句式组在 `v1_families.py` 中，参考译文由 Codex 独立编写和核对，不由 Qwen3-32B 自评得出。
每组 20 个偶数数量变体，两个方向共 40 条，同组全归同一个集合。共有 75 个训练组 / 25 个开发组 / 25 个测试组，分别 3,000 / 1,000 / 1,000 条。
数量变体增加数字和格式训练机会，但不等于 5,000 种独立语义；本轮覆盖仍受 125 个句式限制。

验收检查：完整翻译当前文本；保留人称、语气、否定、条件、数量和单位；术语与上下文相符；问句不回答、公式不解题、片段不续写；代码、占位符、URL 和字面标签保留；译文只在 JSON 的 translation 字段内。
中文数字槽位一律保留阿拉伯数字，且仅作同样含义的数值替换。英文模板的复数结构使用 2–40 的偶数，不产生单复数冲突。

训练集仍调用 Qwen3-32B 生成最终 JSON 候选。候选完全匹配已验收参考时保留；否则替换为已核对的参考表达，并保存原始候选、最终文本、指纹和动作。
替换涵盖合法的不同措辞、口语润色和真正的翻译错误，因此**替换率不是错译率**。
这是一种以独立参考约束的样本验收流程，不声称逐行自由文本主观打分，不使用标注模型自评作为独立质量证明。

完整开发集用于 loss 评估。100 条冻结筛查集合覆盖每个保留句式组的两个方向、一个可选术语变体和一个无额外输入变体；模型效果报告明确区分 100 条筛查与完整 1,000 条测试。
测试内容不参与训练或修改训练目标。后续补充更多原创对话、长段落和自然场景时，应新增来源组，避免仅继续增加数字变体。
